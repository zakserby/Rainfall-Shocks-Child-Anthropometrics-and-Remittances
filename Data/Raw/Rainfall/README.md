# Raw rainfall data

The raw CHIRPS v2.0 monthly precipitation file is not included because it exceeds GitHub's file size limit. The analysis does not need it, as the cleaned municipality rainfall panel is in `Data/Cleaned/Rainfall`.

To rebuild the rainfall panel, download the file from the UCSB Climate Hazards Center and place it in this folder:

https://data.chc.ucsb.edu/products/CHIRPS-2.0/global_monthly/netcdf/chirps-v2.0.monthly.nc
